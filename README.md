# 🎓 TPO Portal

A comprehensive Training & Placement Management System built to modernize the placement process for colleges. The platform centralizes student information, recruitment activities, placement records, and administrative operations into a single, efficient system.

## 🌟 Overview

TPO Portal enables students to maintain up-to-date placement profiles while providing the Training & Placement Office with powerful tools to manage student data, monitor placement progress, communicate with students, and generate reports.

The system is designed with scalability, security, and maintainability in mind, making it suitable for long-term institutional use.

## 🛠️ Technology Stack

| Layer | Technology |
|--------|------------|
| Frontend | React.js (Vite) |
| Styling | Tailwind CSS + shadcn/ui |
| Backend | Node.js + Express.js |
| ORM | Prisma |
| Database | MySQL |
| Authentication | JWT + bcrypt |
| File Upload | Multer |
| Email Service | Brevo |

| Version Control | Git & GitHub |
